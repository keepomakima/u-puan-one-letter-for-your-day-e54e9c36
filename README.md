# One Letter for Your Day

Entry for the make.fun bounty
[u-puan-one-letter-for-your-day-e54e9c36](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

A program (`main.py`, Python 3.13, stdlib-only) that writes exactly one
character to `/output/entry.txt`: the letter **D**.

## The letter

> D — for "doomscrolling": scrolling bad news in bed at 3 a.m. instead
> of sleeping.

One character (1–1 gate), UTF-8, deterministic, no newline — a trailing
newline would make it 2 characters and fail the gate.

Why D: "doomscrolling" is the sharpest picture of the day behind any
single letter — vivid and specific (criterion 2), funny (criterion 3),
and true to a real 2026 night (criterion 4) — and D is its genuine
initial (criteria 1 and 5). It beat "zero sleep" (Z), "unhinged" (U),
"knackered" (K), "overcaffeinated" (O), "exhausted" (E) and "quietly
quitting" (Q) in a head-to-head local judging against the published
judge brief, and far fewer entries share the letter D than Z.

## Run

```sh
python3 main.py   # writes /output/entry.txt (exactly 1 byte: "D"), exit 0
```
